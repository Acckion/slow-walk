# API Examples

`health-response.json` 与 `api-error.json` 仍可用于基础 contract 说明。

`risk-assessment-request.json` 和 `risk-assessment-response.json` 是已经移除的
`/api/v1/risk/assess` raw-risk 协议历史样例，只为版本考据保留。当前 App、Server、
演示或新代码均不得使用它们；canonical Medicine 样例位于 `demo-fixtures/`。

全部内容都是 `DEMO DATA — NOT FOR CLINICAL USE`，示例 URL 使用保留的
`.invalid` 域名，不代表真实医学来源。
